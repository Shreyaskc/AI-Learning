Chapter 6: Evaluation, leakage and decision quality. Count outcomes before naming scores.

With 100 truly urgent tickets, a system catches 80 and misses 20. Among 900 non-urgent tickets it flags 90. True positives true positives equals 80, false negatives false negatives equals 20, false positives false positives equals 90, true negatives true negatives equals 810. Precision is true positives divided by (true positives plus false positives) equals 80 divided by 170 approximately zero point four seven one. Recall is true positives divided by (true positives plus false negatives) equals zero point eight. Accuracy is (true positives plus true negatives) divided by 1000 equals zero point eight nine. F1 is the harmonic mean of precision and recall, about zero point five nine three. It ignores true negatives and assumes a particular balance; it is not the objective for every workflow.

Sweeping thresholds traces precision-recall and receiver-operating-characteristic curves. R O C uses true-positive versus false-positive rates; a low false-positive rate may still create many false positives in a very large negative population. precision recall behavior depends on prevalence. Area under a curve measures ranking across thresholds, while your deployment uses an operating point with an action budget. For top-k review queues use precision@k, recall@k and urgent cases caught within the service window.

For numeric targets, mean absolute error is easy to interpret in target units; root mean square error emphasizes large misses. Percentage errors can explode near zero. For probabilistic prediction use proper scoring rules such as log loss or Brier score the mean squared difference between predicted probability p and observed target y. A model is calibrated if events assigned probability p occur about fraction p over the relevant population. Good ranking, good calibration and good action utility are distinct properties.
