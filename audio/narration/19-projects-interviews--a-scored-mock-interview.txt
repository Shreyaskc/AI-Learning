Chapter 19: Projects, mastery gates and interview practice. A scored mock interview.

Use 75 minutes: 10 minutes foundations, 15 implementation and debugging, 35 design, 10 failure injection and 5 reflection. Have a reviewer choose one unseen variation.

Foundation prompts: explain training versus inference using a concrete predictor; compute precision from true positives equals 30,false positives equals 70; derive the sigmoid and log-loss gradient; explain why cosine is not calibrated relevance. Answer anchors: parameter changes versus fixed application; precision equals zero point three; The derivative of loss with respect to logit z is predicted probability p minus target y then multiply by input; geometric score does not establish event frequency.

Implementation prompt: a model has superb test performance but collapses online. Model answer: reconstruct decision time and data lineage, inspect target and post-outcome fields and entity and time overlap, audit train-only preprocessing, compare feature parity and label maturity, then evaluate shift and selection. “Use a bigger model” is premature because the evaluation may be invalid.

Design prompt: build a multi-tenant documentation assistant for 10,000 employees. Clarify active traffic, document count and size and update rate, permission complexity, residency, latency and quality targets, escalation and budget. A strong design includes versioned ingestion, permission-aware retrieval, ranking, evidence assembly, generation contract, abstention, caches scoped by identity and policy and version, evaluation and human ownership.

Worked capacity assumptions: 2% of employees simultaneously active is 200; if each active user sends one request every 20 seconds, average arrival rate is 10 requests per second. At hypothetical mean response time 4 s, Little's law gives mean concurrency 40. At 2,000 prompt and 300 generated tokens per request, token traffic averages 20,000 input and 3,000 output tokens per second. Those arithmetic loads do not prove a serving cluster can handle them. Benchmark actual context distributions and headroom. If assumed prices were 1 dollar per million input tokens and 4 dollars per million output tokens, cost per request would be zero point zero zero two plus zero point zero zero one two equals 0.0032 dollars before retrieval and infrastructure. These invented prices are for arithmetic only, not current vendor pricing.

Failure injection: permissions change while answers are cached; a source contains injection; one tenant floods long prompts; embedding migration changes dimension; a tool times out after executing. Model answer: invalidate and version authorization caches, enforce trusted boundaries, admit by resource budget with quotas, dual-index and validate migration, query operation status and idempotency before retry. Explain remaining consistency windows rather than claiming perfect instant behavior.
