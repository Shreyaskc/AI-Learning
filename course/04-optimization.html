04 · Optimization: how learning changes parameters

Listen to this section →

Prerequisites: 02–03. Outcomes: derive a training update, diagnose optimization versus generalization failure, and understand regularization.

Suppose a model predicts a delay of two days and the observed delay is five. Which number inside the model should change, in which direction, and by how much? The gradient from 02 supplies direction; a loss supplies the quantity we want to reduce.

An objective connects data to parameters

Listen to this section →

Call all adjustable model numbers theta. Let L measure one prediction error, and J the average training error. For examples (x_i,y_i), empirical risk is that average loss J(theta)=(1/n)sum_i L(f_theta(x_i),y_i). It measures fit on this sample. Population risk is the expectation over future examples; minimizing sample loss does not guarantee minimizing that expectation. A penalty can prefer some solutions even when their sample fit is similar. Its strength is lambda; w is the vector of penalized weights. Adding this regularizer gives: J_reg=J+(lambda/2)||w||². L2 penalizes large coefficients; it is a modeling choice related to a preference for smoother or smaller-coefficient solutions, not universal protection against leakage.

Gradient descent uses the gradient as a direction and a positive step size eta, called the learning rate: w_new=w-eta*gradient(J). In one-feature regression with J=(wx-y)²/2, gradient is (wx-y)x. At x=2,y=5,w=1, gradient=-6. With eta=.1, new w=1.6, prediction 3.2, loss drops from 4.5 to 1.62. With eta=1, w=7 and loss becomes 40.5. The direction was right locally, but the step overshot.

With eta=.1 in the same one-example problem, the next update takes w from 1.6 to 1.96: residual 3.2-5=-1.8, gradient -3.6, update +.36. Repeating this calculation is training; choosing an oversized step can undo progress.

For many examples, average the per-example gradients. Full-batch descent uses the entire training set for each update; stochastic gradient descent uses one or a small batch. A minibatch trades noisy estimates for cheaper and more frequent updates. Shuffle only in ways compatible with the data and model; sequence labels and time-based evaluation still require care. An epoch is a pass through the training examples, not a universal unit of compute across datasets.

Lab and reasoning

Listen to this section →

Run learning.py. It trains a tiny logistic model using analytic gradients and checks a gradient numerically. Sigmoid maps a real score into a number between zero and one. Logistic prediction is p=sigmoid(z)=1/(1+exp(-z)); z=w·x+b. Combining sigmoid with binary log loss yields dL/dz=p-y, hence dL/dw=(p-y)x. Derivation: dL/dp=(p-y)/(p(1-p)); dp/dz=p(1-p); the factors cancel. This cancellation is why the training update has a simple form.

Generalization and regularization

Listen to this section →

Underfitting means the model or procedure cannot fit relevant structure; both train and validation errors can be high. Overfitting means training fit improves while validation performance worsens. More parameters are not the only cause: repeated hyperparameter search can overfit validation, and clean labels matter.

Regularization options include L2, L1 (which can induce sparse coefficients), early stopping using validation, data augmentation that preserves the target, and dropout in neural networks. The train/validation gap is a clue, not a diagnosis by itself. Distribution shift and mislabeled validation data can create similar symptoms.

For regression with both X and y centered (recover the intercept as mean(y)-mean(X)·w), solving normal equations XᵀXw=Xᵀy is possible when the system is suitably nonsingular. Avoid computing a literal matrix inverse in numerical software; factorization or least-squares solvers are typically more stable. Gradient methods matter when data or models make direct solvers inappropriate.

Curvature and conditioning

Listen to this section →

A convex function lies below the line joining any two points on its graph. For a differentiable convex objective, a stationary point is a global minimum. Linear least squares is convex in its coefficients; a deep network's objective generally is not. The Hessian contains second partial derivatives and describes local curvature. A narrow valley with very different curvature across directions is ill-conditioned: one learning rate may oscillate in one direction and crawl in another. Scaling inputs can help; it does not eliminate every source of poor conditioning.

The optimizer names in this paragraph are an optional orientation. Momentum smooths gradient history: v_t=beta*v_(t-1)+(1-beta)*g_t, then step along v_t. Adam keeps running averages of gradients and squared gradients. It corrects the early averages for their initialization and scales each coordinate by a stabilized square root of its squared-gradient average. These averages are also called first and second moments. It adapts coordinate step scales. AdamW decouples weight decay from the adaptive gradient calculation. These are optimization procedures, not substitutes for validation. Scheduler, batch size, precision and initialization can all alter behavior.
